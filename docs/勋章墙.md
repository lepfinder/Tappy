# Feature PRD: Gamification Badge System (12-Badge MVP)

## 1. 目标 (Goal)
在“个人中心”页面增加一个**勋章墙 (Badge Wall)**，包含 12 个核心成就。
实现勋章的**自动解锁逻辑**、**数据持久化**以及**解锁时的庆祝弹窗**。

## 2. 技术栈 (Tech Stack)
*   **Data**: Dexie.js (Store unlocked badges).
*   **UI**: React + Tailwind CSS.
*   **Icons**: 使用 **Emojis** 作为勋章图标（因为它们自带颜色，适合儿童风格），或者使用 Lucide-react + 颜色背景。**本方案建议使用 Emojis 以降低设计成本。**
*   **Animation**: `framer-motion` (for unlock popups).

## 3. 数据库设计 (Schema)

请更新 `src/db.ts`：
1.  新增表 `user_badges`。
2.  Schema: `user_badges: 'id, userId, badgeId, unlockedAt'` (id is composite `${userId}_${badgeId}`).

## 5. 给 AI 的分步执行指令 (Step-by-Step Prompts)

请按顺序发送以下指令，以保证代码质量。

### Step 1: 数据库与配置 (Data Layer)
> **Prompt:**
> "Let's build the Badge System.
> 1. Update `src/db.ts`: Add a `user_badges` table (schema: `++id, userId, badgeId, unlockedAt`).
> 2. Create `src/data/badges.ts`: Export a constant `BADGES` array containing the 12 badges defined in the PRD (use the IDs, Emojis, and Names provided). Add a `description` field for the unlock condition text.
> 3. Create a helper function `getUnlockedBadges(userId)` that queries Dexie and returns an array of badge IDs."

### Step 2: 核心解锁逻辑 (The Engine)
> **Prompt:**
> "Create a hook `useBadgeSystem.ts` to handle unlocking logic.
> It needs a function `checkAndUnlockBadges(userId, sessionResult)` that runs after a practice session.
>
> **Logic Requirements:**
> 1. Fetch user's history from Dexie to calculate total time, streaks, etc.
> 2. Iterate through all `BADGES`.
> 3. Check if the user *already* has the badge. If yes, skip.
> 4. If no, check the condition (e.g., if `badge.id === 'snail_run'`, check if `sessionResult.wpm >= 5`).
> 5. **Special Logic**: For 'Identity', check it when the user updates their profile.
> 6. If a condition is met:
>    - Save to `db.user_badges`.
>    - Return a list of `newlyUnlockedBadges` to trigger a UI popup."

### Step 3: UI - 勋章墙组件 (Badge Wall UI)
> **Prompt:**
> "Create a `BadgeSection` component to display inside the User Profile page.
> **Layout**: A responsive Grid (4 columns on desktop, 3 on mobile).
> **Visual States**:
> - **Unlocked**: Show the Emoji large, colorful background (yellow/blue pastel), and the badge name. Add a shine effect.
> - **Locked**: Show the Emoji in Grayscale (filter: grayscale(1)), opacity 50%, with a Lock 🔒 icon overlay.
> **Interaction**: Clicking a locked badge shows a Toast/Tooltip saying 'Hint: [Description]'."

### Step 4: UI - 解锁庆祝弹窗 (Celebration Modal)
> **Prompt:**
> "Create a `BadgeUnlockModal` component.
> This modal appears immediately when `newlyUnlockedBadges.length > 0`.
> **Features**:
> 1. Confetti animation (use `canvas-confetti` if possible, or simple CSS particles).
> 2. Show the unlocked badge Emoji huge in the center with a bounce animation.
> 3. Title: 'New Badge Unlocked!'
> 4. Button: 'Awesome!'"

### Step 5: 整合 (Integration)
> **Prompt:**
> "Integrate everything:
> 1. In `PracticePage` (Result Modal), call `checkAndUnlockBadges`. If it returns new badges, show the `BadgeUnlockModal`.
> 2. In `UserProfile`, render the `BadgeSection`."

### 6. 给开发者的额外提示 (Tips for You)

*   **关于“连续打卡”的算法**：
    AI 可能会把“连续打卡”写得很复杂。最简单的逻辑是：
    *   获取用户所有练习记录的 `timestamp`。
    *   转成 `YYYY-MM-DD` 格式并去重。
    *   排序，然后检查是否连续（今天、昨天、前天...）。
*   **关于 Emojis**：
    使用 Emojis 是最省事的，但不同系统（Windows vs Mac）显示的 Emoji 样子不一样。
    *   *Mac*: 非常漂亮 3D 质感。
