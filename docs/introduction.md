# Tappy —— 有趣的儿童打字启蒙乐园 🐻⌨️

## 产品简介

**Tappy** 是一款专为儿童设计的打字启蒙 Web 应用，融合趣味游戏化元素与科学的教学设计，让孩子们在轻松愉快的氛围中掌握键盘打字技能。无论是英文字母、单词，还是中文拼音、古诗词，Tappy 都能让打字练习变得像玩游戏一样有趣！

## 🧠 教学设计理念

### 循序渐进

从简单的字母认识开始，逐步过渡到单词、短句、短文，难度阶梯式提升，让孩子始终保持适度的挑战感。

### 即时反馈

每次敲击都有视觉反馈，正确会立即前进，错误会有明显提示，帮助孩子即时纠正。

### 关卡式设计

每个模式都包含多个关卡，完成后有成就感，激励孩子持续练习。统计数据包括：

- ⚡ **WPM（每分钟字数）**：打字速度指标
- 🎯 **准确率**：正确敲击的百分比
- 🔥 **连击数**：连续正确输入的次数
- 📊 **错误统计**：帮助识别薄弱环节

### 寓教于乐

百米竞速模式将打字练习变成刺激的赛跑游戏，孩子打字越快，屏幕上的角色就跑得越快，极大提升练习的趣味性和目标感。

## 📖 课程内容示例

### 古诗词示例 —— 《静夜思》（唐·李白）

```
床前明月光   chuáng qián míng yuè guāng
疑是地上霜   yí shì dì shàng shuāng  
举头望明月   jǔ tóu wàng míng yuè
低头思故乡   dī tóu sī gù xiāng
```

孩子通过键入拼音来完成古诗，同时还能看到英文翻译：
> "Moonlight before my bed, I suspect it is frost on the ground. I raise my head to look at the bright moon, I lower my head and think of my hometown."

### 短文示例 —— 《荷叶圆圆》

> 荷叶圆圆的，绿绿的。小水珠说：荷叶是我的摇篮。小蜻蜓说：荷叶是我的停机坪...

通过拼音输入方式，孩子在练习打字的同时，也在阅读和理解这些优美的课文。

## 🚀 快速开始

### 在线使用

直接访问在线版本，无需安装：[Tappy 在线版](#)

### 本地运行

```bash
# 克隆项目
git clone https://github.com/your-username/Tappy.git

# 安装依赖
cd Tappy
npm install

# 启动开发服务器
npm run dev

# 访问 http://localhost:3000
```

### 部署到 Netlify

项目已配置 `netlify.toml`，只需：

1. 将代码推送到 GitHub
2. 在 Netlify 连接仓库
3. 自动构建并部署
